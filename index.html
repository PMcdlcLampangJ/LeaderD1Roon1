แบบประเมินรายวิชา
หลักสูตรสร้างผู้นำการเปลี่ยนแปลงขับเคลื่อนตำบลเข้มแข็ง

ตามหลักปรัชญาของเศรษฐกิจพอเพียง ประจำปีงบประมาณ พ.ศ. 2570

คำชี้แจง: แบบประเมินนี้จัดทำขึ้นเพื่อวัดและประเมินผลการจัดกิจกรรมการเรียนรู้ เพื่อนำข้อมูลไปปรับปรุงและพัฒนาการดำเนินงานต่อไป ขอความกรุณาตอบแบบสอบถามตามความเป็นจริง โดยแบ่งเป็น 3 ตอน

2

ตอนที่ 2 ความพึงพอใจต่อการจัดกิจกรรมการเรียนรู้ (2 วิชา)

เกณฑ์ประเมิน: 5 = มากที่สุด, 4 = มาก, 3 = ปานกลาง, 2 = น้อย, 1 = น้อยที่สุด

คะแนนเฉลี่ยรวม 2 วิชา: 0.00 / 5.00
สเกลระดับคะแนน: 5 มากที่สุด 4 มาก 3 ปานกลาง 2 น้อย 1 น้อยที่สุด
วิชาที่ 1: วิชา ผลสำเร็จของผู้นำการเปลี่ยนแปลงและกรอบแนวทางโครงการเสริมสร้างและพัฒนาผู้นำการเปลี่ยนแปลง ปี 2570 เฉลี่ย 0.00
1. เนื้อหาช่วยให้เข้าใจบทบาทและภารกิจของผู้เกี่ยวข้องในการขับเคลื่อนโครงการในระดับพื้นที่
2. ระยะเวลาการบรรยาย (2 ชั่วโมง) เหมาะสมกับขอบเขตเนื้อหา
3. วิทยากรมีความรู้ความเชี่ยวชาญด้านการขับเคลื่อนงานพัฒนาชุมชน
4. สื่อประกอบการบรรยายมีความชัดเจนและช่วยให้เข้าใจง่ายขึ้น
5. ผู้เข้าอบรมได้รับความรู้ และทักษะเพิ่มเติมจากวิชานี้
6. ผู้เข้าอบรมสามารถนำแนวคิดไปประยุกต์ใช้ในการทำงานจริงในพื้นที่ได้
วิชาที่ 2: ผู้นำการเปลี่ยนแปลงกับบริบทและสถานการณ์ความเปลี่ยนแปลงในอนาคต เฉลี่ย 0.00
1. เนื้อหาครอบคลุมสถานการณ์สังคม แนวโน้มการเปลี่ยนแปลง และผลกระทบต่อคน ครัวเรือน และชุมชน
2. ระยะเวลาการบรรยาย (2 ชั่วโมง) เหมาะสมกับขอบเขตเนื้อหา
3. การแบ่งกลุ่มฝึกปฏิบัติ (1 ชั่วโมง) ช่วยให้ผู้เข้าอบรมวิเคราะห์สถานการณ์ปัญหาในพื้นที่ได้ดีขึ้น
4. วิทยากรมีความเชี่ยวชาญด้านสถานการณ์สังคม การวิเคราะห์การเปลี่ยนแปลงของโลกในอนาคต
5. ผู้เข้าอบรมสามารถวิเคราะห์สถานการณ์สังคมและผลกระทบต่อชุมชนและเสนอแนวทางการขับเคลื่อนงานที่เหมาะสม
6. สื่อประกอบการบรรยายมีความชัดเจนและช่วยให้เข้าใจง่ายขึ้น
7. ผู้เข้าอบรมได้รับความรู้ และทักษะเพิ่มเติมจากวิชานี้
8. ผู้เข้าอบรมสามารถนำแนวคิดไปประยุกต์ใช้ในการทำงานจริงในพื้นที่ได้

เชื่อมต่อ Google Sheets ผ่าน Google Apps Script

รับข้อมูลผลการประเมิน 2 วิชาเข้าชีตแบบอัตโนมัติทันที

1. ตั้งค่า Webhook URL:

เมื่อบันทึกแล้ว ระบบจะส่งข้อมูลตรงเข้า Google Sheet ทุกครั้งที่กดยืนยัน

2. โค้ด Google Apps Script (ฉบับ 2 วิชาหลัก):
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    // สร้างหัวตารางอัตโนมัติเมื่อเป็นแผ่นงานว่าง
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "วันที่เวลา", "เพศ", "อายุ", "วุฒิการศึกษา", "สถานะทางสังคม",
        "วิชาที่ 1 เฉลี่ย (6 ข้อ)", "วิชาที่ 2 เฉลี่ย (8 ข้อ)", "คะแนนเฉลี่ยรวม 2 วิชา",
        "จุดเด่นหรือสิ่งที่ประทับใจ", "สิ่งที่ควรปรับปรุงพัฒนา", "ข้อเสนอแนะวันถัดไป", "คะแนนรายข้อ (JSON)"
      ]);
    }
    
    sheet.appendRow([
      new Date(),
      data.gender,
      data.age,
      data.education,
      data.role,
      data.scores.avg1,
      data.scores.avg2,
      data.scores.overall,
      data.suggestions.strengths,
      data.suggestions.improvements,
      data.suggestions.nextdays,
      JSON.stringify(data.scores.raw)
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({ status: "success" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(error) {
    return ContentService.createTextOutput(JSON.stringify({ status: "error", message: error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

ขั้นตอนใน Google Sheets:

  1. เปิด Google Sheet → เมนู Extensions → Apps Script
  2. วางโค้ดด้านบนแล้วกดเซฟ
  3. กด Deploy → New deployment → เลือก Web app
  4. กำหนดสิทธิ์ Execute as: Me และ Who has access: Anyone
  5. นำ Web app URL ที่ได้มาวางลงในช่องด้านบน
